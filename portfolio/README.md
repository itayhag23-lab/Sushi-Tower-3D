# פורטפוליו אישי

אתר סטטי בקובץ אחד. אין build, אין התקנות.

## לפתוח מקומית
פשוט פותחים את `index.html` בדפדפן. זהו.

## איך לערוך
- **טקסטים** — בתוך `<body>`, הכל בעברית וקריא.
- **צבעים ומרווחים** — רק ב-`:root` בראש ה-`<style>`. אסור לשנות צבע בתוך קומפוננטה.
- **פרויקט חדש** — משכפלים כרטיס `<article class="card">` ומחליפים כותרת, תיאור ותגיות.
- **לינק "שחק עכשיו"** — מעדכנים לכתובת החיה אחרי פרסום המשחק.

## לפרסם
גוררים את התיקייה ל-vercel.com, או מפעילים GitHub Pages על התיקייה הזו.
