# Beautiful UI

מטרה: פלט שנראה כמו מוצר, לא כמו דמו.

## שלב 1 — כיוון לפני קוד
לפני שכותבים שורת CSS, קובעים בשלוש שורות:
- **Mood:** (לדוגמה: יפני מינימליסטי / ארקייד ניאון / פסטל רך)
- **פלטה:** רקע, משטח, טקסט ראשי, טקסט משני, צבע מותג, צבע הצלחה, צבע שגיאה.
- **פונט:** כותרות + גוף.

אם המשתמש לא נתן כיוון — הצע אחד ותמשיך. לא לשאול שאלות מיותרות.

## שלב 2 — טוקנים
כל הערכים ב-`:root` כ-CSS variables. אסור ערך קשיח בתוך קומפוננטה.
```css
:root{
  --bg:#0e0f13; --surface:#181a21; --text:#f2f3f5; --muted:#9aa0ab;
  --brand:#ff6b6b; --radius:14px;
  --space-1:4px; --space-2:8px; --space-3:16px; --space-4:24px; --space-5:40px;
  --ease:cubic-bezier(.4,0,.2,1);
  --shadow-1:0 1px 2px rgba(0,0,0,.2), 0 4px 12px rgba(0,0,0,.18);
}
```
מצב בהיר/כהה: `@media (prefers-color-scheme: dark)` + אפשרות override ב-`[data-theme]`.

## שלב 3 — הדברים שמפרידים בין "AI" ל"מעוצב"
- **רקע לא שטוח:** gradient עדין, noise, או vignette. לא צבע אחד אחיד.
- **קונטרסט בגדלים:** כותרת ראשית לפחות פי 2.5 מגוף הטקסט.
- **משקל אופטי:** כותרות 700–800, גוף 400, לייבלים 600 + letter-spacing קטן.
- **פינות עקביות:** רדיוס אחד לכל הכרטיסים, רדיוס קטן יותר לכפתורים.
- **מסגרת עדינה:** `1px solid rgba(255,255,255,.06)` על משטחים כהים מוסיף איכות.
- **מיקרו-אנימציה:** כניסה של אלמנטים ב-stagger של 40ms, hover שמזיז 1-2px.
- **מצב ריק ומצב טעינה** מעוצבים, לא טקסט חשוף.

## שלב 4 — בדיקה לפני שמסיימים
עבור על הרשימה וכתוב בפירוש מה עבר:
- [ ] 375px בלי גלילה אופקית
- [ ] focus-visible נראה במקלדת
- [ ] קונטרסט טקסט ≥ 4.5:1
- [ ] אין ערך צבע/מרווח קשיח מחוץ לטוקנים
- [ ] `prefers-reduced-motion` מכבה אנימציות
- [ ] RTL תקין אם יש עברית

GSAP (אנימציה), Lenis (גלילה חלקה), Three.js (תלת מימד), Chart.js (גרפים), Lucide (אייקוני SVG).
